# 火、水、管線完成條件

本輪延續第一關與既有素材，保留 120 秒布丁期限、10 公尺管長、操作與解謎順序。版本候選 v0.2.5。程式驗證、代理畫面檢查及使用者接受分開記錄。

1. **接觸與水量**　供水、水滴、碰撞飛濺、地板／檯面、水蒸汽與排出使用同一份水量。只有實際抵達承接表面的水能改變火格。每次傳熱扣除真正蒸發的水量，剩餘水仍能流動。冷地板不蒸發；普通火可消耗停噴後的水灘；油鍋維持獨立錯誤反應及蘇打粉解法。
2. **完整生命週期**　開始噴、轉向、停噴、拔管、換工具後的空中水繼續飛行並碰撞。水灘增加、合併，牆與櫃體阻擋，檯面與地板分開。單一水滴不需要 Rigidbody，以固定步進及數量上限維持成本。
3. **管線**　同一接觸路徑負責碰撞、計長與可見管身。餘長未用盡時不可因普通撞牆累積斷裂張力。滿長持續外拉才斷開，來源停水，管線沿安全路徑慢快慢收回玩家接頭。回收期間移動及跨過門口也須保持兩端協調。
4. **真正救援**　命令式整關須由玩家清出 NPC 實際可走的撤離走廊。不能只等待全屋燃料自行耗盡。最後撤離路徑清理完成後 30 秒內須完成救援，否則失敗並保留路徑證據。計時及 NPC 速度不變。
5. **交付**　先跑針對傳熱、水量、隔牆、檯面／油鍋及管線的驗證，再走整關。檢查正常相機距離的連續畫面與 CPU 步進成本。必要驗證通過後建置本機 Windows 玩家版並在玩家版重跑關鍵情境；使用者畫面接受仍須另行確認。

已重現的基準缺口是既有積水不參與後續火接觸。`Logs/Physics025/baseline-standing/results.txt` 記錄停噴六秒後，6 單位表面水遇到強度 0.65 的火，兩秒後水量、火強度與蒸發量皆完全不變。修正會以此反例與水量轉移驗證，避免只增加視覺效果。
