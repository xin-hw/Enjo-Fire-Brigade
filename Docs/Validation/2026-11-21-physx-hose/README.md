## 管身與收管

每節已展開的管身有剛體、膠囊碰撞和可彎曲的 PhysX 關節，最多 72 節。網格跟隨原生模擬的位置。來源接頭的實際反力與 10 公尺儲備決定何時限制向外移動。放開會解除持續拉扯，符合受力條件約 0.65 秒後來源接頭脫開。

回收端以有力上限的關節牽引材料。只有管身真的抵達角色接頭才捲入，收管途中遇到門角會放慢。已發射的水繼續飛行。換來源會等舊管回收完，遊戲顯示收管提示。

牆角測試曾量到 8 公分的碰撞穿入。整關試跑又重現了拖著回收中的管身過門時長鏈失穩。成品採用 TGS、每 0.01 秒更新物理、管身專用的解算精度與有限力捲收。初始管身從既有馬桶來源出口離開碰撞盒再下垂，來源配件可在脫開後恢復與來源模型碰撞。斧頭和噴槍的查詢會略過自己的軟管。
